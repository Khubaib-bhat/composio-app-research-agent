Mapping 100 apps for AI-agent toolkit readiness

An evidence-first research pipeline that turns developer documentation into structured integration decisions, then verifies uncertain and high-impact claims.

Integrity note: Accuracy percentages are intentionally not hard-coded. They should be generated only after the research and verification runs, so the case study never presents fabricated confidence or validation numbers.

Decision model

For every app the agent records authentication, credential access, API type/breadth, MCP availability, buildability, blocker, evidence and confidence. Unknown is a valid output. Search snippets are discovery aids rather than proof.

Verification loop

  1. Flag low-confidence or evidence-free records.
  2. Re-check authentication and developer-access claims against official documentation.
  3. Distinguish official MCP from community implementations.
  4. Manually spot-check a fixed sample and record every correction.
  5. Recompute accuracy after corrections.

Composio implementation

The pipeline is designed around Composio's current sessions-first SDK. Current documentation recommends composio.sessions.create(...); for MCP, create a session with mcp=True and use session.mcp.url and session.mcp.headers. The older standalone MCP server API is documented as deprecated.
